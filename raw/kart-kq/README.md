# raw/kart-kq — Meshy remaster parts for ARCIRCLE KART

Made by a Meshy worker session on 2026-10-30 for the game session to pack and place. Nothing here is used by the game yet. Every model is **raw**: the textures were already shrunk to 1024 px (metal/roughness 512 px; JPEG colour/MR, PNG normals) so each file is below 3 MB, but the geometry is Meshy's output as it came (not welded, quantized or compressed). Pack each one with `tools/pack-prop.mjs` + `tools/ktx-hero.mjs` (KTX2 ≤ 1024 px, 512 px for small props) and instance repeats.

- `ref/`: our real screenshots, the references (committed earlier).
- `DIFF.md`: what the mock-ups have that our game doesn't, as a to-do list.
- Task ids: a text-to-3d row lists preview → refine. Any task can be read again with `node tools/meshy.mjs get <kind> <id>`.
- Tool change: `tools/meshy.mjs img2img` now takes `--ratio` (Meshy's `aspect_ratio`). Without it the image-to-image output is 1024×1024 whatever the reference is, which squashed the first set of 16:9 mock-ups, so I redid them at 16:9 (race) and 9:16 (pick).
- Credits: 2,732 at the start, about 1,980 after (≈ 750 used).
