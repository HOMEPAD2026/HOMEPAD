# raw/rm — Meshy raw outputs for the ARCIRCLE Studio remaster

Raw, unconverted Meshy outputs (the main session keys, resizes and packs them). Made 2026-10-27 with `tools/meshy.mjs`, model nano-banana for images.

Notes:
- Cut-outs were asked on flat pure green; Meshy returned somewhat muted greens (not exact #00FF00) — key by hue. Glows are on black (draw additively).
- Meshy text-to-image accepts only 1:1 16:9 9:16 4:3 3:4 3:2 2:3, so banner-bg.png and tabbar.png are 16:9 (21:9 was refused).
- start-pad.glb: text-to-3d preview + refine, target 6000 polys → 5,901 triangles, so no remesh was needed.
