# raw/feat — "Built to play together" feature-card icons

Made with Meshy text-to-image (`node tools/meshy.mjs image "<prompt>" --ratio 1:1`, model nano-banana), 1024×1024 PNG.

Backgrounds are flat (border std ≤ 3 per channel) but Meshy renders a lime green rather than exact #00FF00; the measured border colour of each file is listed so it can be keyed out.

Earlier attempts were rejected: the first round had muted gradient backgrounds, text on the coins ("EARN AS YOU PLAY"), framed flat cards for devices/pets, and an Earth-map globe; the second round's world (faint continents) and together (no heart, not a high-five) were made again.
