Before you pair against a Stock Token
  • Stock Tokens are Robinhood's, not HOMEPAD's. They're tokenized debt securities issued by Robinhood Assets (Jersey) Limited — HOMEPAD only reads their public registry and pairs against them the same way it can pair against any ERC-20.
  • Known, unresolved pricing risk. Every Stock Token carries a currentMultiplier that Robinhood adjusts on real corporate actions (splits, dividends). HOMEPAD's Paired factory does not re-sync a pool's price to that multiplier after launch — a corporate action after your launch could leave the pool mispriced relative to the real stock. This is why Stock Token pairing has stayed off the main launch form's quote list; it's opt-in here, with this stated plainly.
  • Addresses are resolved live, every page load, from Robinhood's own asset API — never hardcoded here. If a ticker doesn't appear in the list below, Robinhood's registry doesn't currently list it as tradable on Robinhood Chain.
